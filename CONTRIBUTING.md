
# Testing
It is expected that all contributions be fully regression tested by the contributor to the best of their ability. This
includes running a full bootstrap cycle for the latest supported version on (at least) 64-bit debian-based linux.

# LLM Policy
Short version: All code submitted must be majority-written by a human, and commit messages/merge descriptions must be
free of all LLMisms. If you didn't want to write it, why should a maintainer read it?

## Allowable usage
- Feeding the codebase or documentation to AI for investigation purposes
- Querying AI for potential solutions
- Very small or simple changes (e.g. catching a logic error)

## Banned usage
- Large blocks of AI generated code (e.g. more than 5 lines)
- AI generated commit messages or merge request descriptions
- AI generated documentation
